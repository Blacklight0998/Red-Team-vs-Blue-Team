# Project Overview

## Objective

This project models a controlled **Red Team vs Blue Team** exercise in an authorized university lab environment.

The Red Team generates reconnaissance, authentication and network activity. The Blue Team monitors that activity, identifies suspicious behavior and applies defensive controls.

## Responsibilities

### Red Team — Andy Vega Araya

- reconnaissance;
- service discovery;
- controlled authentication testing;
- network/packet experimentation;
- offensive test reporting.

### Blue Team — Gabriel Villalobos Alpízar

- network monitoring;
- failed-login monitoring;
- behavior-based detection;
- firewall hardening;
- automated defensive response;
- alerting and visualization.

## Evidence

Evidence is intentionally added only as the team completes and validates each stage of the project.

Planned evidence categories include:

- Red Team execution screenshots;
- Blue Team detection output;
- logs and alerts;
- defensive response evidence;
- test reports;
- final findings.

## Important limitation

This repository combines two contributors' work as one group project. It should not be interpreted as evidence that one person individually implemented both sides.
